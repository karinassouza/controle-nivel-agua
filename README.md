controle-nivel-agua
Projeto em Python que simula o controle de níveis de um reservatório de água, utilizando cores no terminal com a biblioteca Colorama.

💧 Controle de Níveis de Água

Sistema simples em Python para monitoramento de níveis de um reservatório.

🚀 Funcionalidades
- Exibição de níveis com cores (Colorama)
- Interação com o usuário
- Simulação de estados do reservatório
